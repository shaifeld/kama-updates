## החלטות ב-kama-connect
- דף הקמה סטטי נפרד בגיטהאב פייג'ס. באפליקציה אין שום מסך של סיסמת בנק, וגם "עדכון סיסמה" פותח את הדף בדפדפן.
- אפליקציית OAuth רגילה עם ההרשאות repo ו-workflow. מי שעובד עם גיטהאב יקבל המלצה לפתוח חשבון נפרד לכספת.
- הצפנה משולבת: המפתח הציבורי בגיטהאב, המפתח הפרטי רק בטלפון (ג'מיני צדק: ב-AES רגיל המפתח חייב לשבת גם בגיטהאב).
- פונקציה נפרדת בקלאודפלייר: CORS רק ל-https://shaifeld.github.io (בלי נתיב), בלי רישום ביומנים.
- פרמטר state נוצר ונבדק בדף ההקמה בדפדפן (sessionStorage), לא בפונקציה.
- אפליקציית OAuth: בלי wildcard, בלי Device Flow, בלי Expire user access tokens (הטופס של גיטהאב כולל היום את השדה הזה).
- כפתור "סנכרן עכשיו" באפליקציה + workflow_dispatch במשימה.
- מסלול גיבוי: הזנת מפתח גישה אישי (PAT) אם אפליקציית ה-OAuth תיחסם.
- טוקן RiseUp באשף נשאר: זה טוקן של שירות חיצוני ולא סיסמת בנק.
- דף ההקמה בלי סקריפטים חיצוניים (ליבסודיום ארוזה במאגר), עם תג CSP קשיח.
- המשימה: contents: write, נעילה (concurrency), ריצה אחת ביום בשעה אקראית, קובץ דופק, קובץ סטטוס עם קודי שגיאה בעברית, moneyman נעול על גרסה בדוקה.
- בסוף ההקמה: "פתח באפליקציה" (הנתונים אחרי #), "העתק קוד", וקוד סריקה למחשב.
- קובץ הגדרות מרוחק config.json במאגר kama-connect: Client ID, כתובת הוורקר, גרסת moneyman, כתובת החזרה. נטען בלי מטמון. החלפת Client ID = עדכון גם בוורקר.
- הצפנה משולבת בליבסודיום crypto_box_seal (מפתחות של 32 בתים, מתאים לקוד סריקה), לא RSA.
- הדף מזהה מאגר קיים: בעדכון סיסמה מחליף רק את סוד הסיסמה ולא נוגע במפתח הציבורי.
- כתובת החזרה זהה תו בתו (כולל / בסוף), Enforce HTTPS בפייג'ס, ומבנה הקישור אחרי # נסגר מול קוד האפליקציה.
- דף ההקמה, מהיום הראשון (ג'מיני): ספריית קוד סריקה ארוזה מקומית; בדיקה שמאגר קיים הוא פרטי לפני כתיבה, ועדכון סיסמה בלי לדרוס מפתח ציבורי; בדיקת scope שחזר (repo + workflow) עם הודעה ברורה; config.json בלי מטמון; המפתח הפרטי נשאר בזיכרון הלשונית עד "סיימתי, האפליקציה מחוברת" + אזהרה לא לסגור; ריצת סנכרון ראשונה בסוף ההקמה.
- רשימת 21 בדיקות אבטחה חובה לפני השקה: security-checklist.txt (מג'מיני, מאושרת).
